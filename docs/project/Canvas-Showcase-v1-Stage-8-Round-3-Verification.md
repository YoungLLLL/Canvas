# Canvium Gallery Showcase v1：阶段 8 第三轮验证记录

> 验收日期：2026-07-22  
> 范围：真实馆藏画廊、筛选与分页、加载状态、图片预算、无图状态、Windows 可读性及核心响应式路径

## 1. 本轮完成

- 将搜索、年份、图片状态与排序从仅辅助技术可见的表单恢复为正式筛选面板；URL 仍是唯一可分享状态。
- 增加可见分页、当前页和可访问作品总数；保留查询条件及中英文切换。
- 将馆藏加载页改为与正式全屏画廊同构的骨架，降低流式切换时的构图跳变。
- 画廊作品保持完整画面，不再裁切；仅资料记录使用独立文字卡，并在详情页明确说明不展示图片的原因。
- 自动滚动画廊从三套副本降为两套；仅首套前两张图片使用 eager/high，其余图片 lazy/auto。
- 页面进入后台时停止动画帧；增加显式暂停／继续控制，悬停和键盘聚焦时暂停。
- 消除循环副本的重复 DOM id 和重复 View Transition 名称，恢复馆藏返回后的焦点定位。
- 恢复共享导航中的中英文切换，并使用 Suspense 保持静态页面可生产构建。
- 将首页指针视差接入当前实际 DOM，减少动态模式下保持静态。
- 更新浏览器测试，使其验证当前正式设计，而不是阶段 4／5 的旧占位结构。
- 按视觉系统重新校正 Windows 浏览器字号：首屏必要信息不再低于 12px，正文与说明文字提升至 14–16px，并恢复约定的中英文字体分工。
- 移除地球画布上的全局灰度／亮度／对比度滤镜；依据视觉系统色值，以现有真实地形数据生成 4096×2048 双色材质（海洋 `#101719`、陆地 `#59584F`），改善模糊和偏色。
- 增加首屏可见文字字号下限和地球画布无滤镜的浏览器回归断言。

## 2. 自动验证

- Prettier：通过。
- ESLint：通过。
- Next.js 路由类型与 TypeScript：通过。
- Vitest：9 个测试文件、30 个测试通过。
- Next.js 生产构建：通过。
- Playwright Chromium（Windows、生产构建）：8 条核心路径通过，耗时 21.7 秒。

浏览器路径覆盖首页与博物馆路由、390×844 首页／博物馆、字体与指针动效、真实馆藏到作品、筛选 URL 与语言切换、返回状态恢复、仅资料作品和移动端筛选／分页。

Windows 1440×1000 与 390×844 抽查中，首屏可见叶子文本均不低于 12px；首页及博物馆地球 canvas 的计算样式为 `filter: none`。

## 3. 当前仍未完成

- 尚未用 Performance trace 给出图片解码内存、LCP、长任务及连续翻页的量化预算。
- 尚未完成 Firefox、WebKit 和更多桌面屏幕尺寸的视觉矩阵。
- 博物馆页的 `motion-reveal` 服务端／客户端初始类名仍会在开发模式产生 hydration 警告；生产路径功能正常，但应在后续动效清理中统一初始状态。
- 当前作品页支持缩放、复位和全屏，但触控拖动与更完整的键盘查看器仍需补齐。
- 对话窗口只有可靠的“人格未发布”状态；真实生成节奏、来源展开和上下文保持依赖阶段 7。
- 阶段 5 约 500 件真实记录长跑尚未执行，图片映射门槛仍不能关闭。
