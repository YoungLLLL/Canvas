# Canvium Gallery Showcase v1：阶段 8 第四轮排版收敛记录

> 验收日期：2026-07-22  
> 范围：首页、博物馆页、馆藏页与作品详情页；1440×1000 桌面端及 390×844 移动端

## 1. 本轮目标

此前多轮修改主要是局部补丁，自动验证通过但页面排版仍未整体收敛。本轮重新以视觉与动效系统基准为准，按完整页面统一字体职责、信息层级、间距、构图和移动端内容流。

## 2. 已完成

- 统一 Demo 派生页面的最终几何覆盖层，减少不同轮次字号、间距和断点规则互相覆盖造成的视觉漂移。
- 修正中文标题字体链，使中文展示文字优先使用 `Noto Serif SC`，正文和控件继续使用 `Noto Sans SC`。
- 首页移动端重新排列今日作品、推荐卡和数字艺术家卡，移除与卡片叠压的地球品牌标题；首页聚焦状态不再显示失真的超大地球回退图形。
- 移动导航不再保留一个孤立的“艺术家”入口，窄屏只保留品牌、语言和搜索操作。
- 博物馆页重新校正移动端品牌标题、馆名、正文、推荐作品、主操作和地球之间的垂直节奏，主操作扩展为完整内容宽度。
- 馆藏页降低桌面和移动端标题的压迫感，重新平衡双语介绍、作品带高度、作品间距、暂停控制和分页位置。
- 作品详情移动端从锁定单屏改为正常文档流：高清作品、完整简介、馆藏信息、媒介尺寸、AI 不可用说明、来源入口和独立观看提示均可滚动访问。
- 缩紧移动查看器控制条，使缩放、复位和全屏操作不再横向溢出。

## 3. 视觉复核

已保存本轮桌面端和移动端的修改前后整页截图，位置为 `evaluation/layout-audit/`。重点复核了：

- 首页卡片叠压与移动端首屏；
- 博物馆页导航、内容宽度和地球起始位置；
- 馆藏页标题、双语说明、作品带与底部控制；
- 作品详情移动端完整内容是否可访问。

## 4. 自动验证

- Prettier：通过。
- ESLint：通过。
- Next.js 路由类型与 TypeScript：通过。
- Vitest：9 个测试文件、30 个测试通过。
- Next.js 生产构建：通过。
- Playwright Chromium（生产构建，单项超时放宽至 90 秒以容纳真实馆藏网络波动）：8 条核心路径通过，耗时 1.6 分钟。

## 5. 仍未完成

本轮解决的是排版与响应式收敛，不代表阶段 8 全部关闭。仍需完成 Performance trace 量化、Firefox／WebKit 视觉矩阵、查看器触控拖动、更完整的键盘查看器，以及依赖阶段 7 的真实对话生成节奏和来源展开。
