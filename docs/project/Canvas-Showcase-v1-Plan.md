# Canvium Gallery Showcase v1 工作计划

> 状态：当前执行基准  
> 更新日期：2026-07-20  
> 正式产品名称：Canvium Gallery
> 目标：完成一座可公开访问、可持续扩展、具有高完成度视觉与动效的线上绘画美术馆。

## 1. 产品定位

Canvium Gallery Showcase v1 不是一次人工策展，也不以短期用户验证为首要目标。它是一套专注二维绘画的线上美术馆系统：客观呈现来自真实美术馆与博物馆馆藏的绘画作品，并通过有规则、有来源边界的 AI 内容生成与艺术家人格，让用户能够观看、理解并围绕当前作品展开对话。雕塑、立体文物和其他需要三维观看的藏品不属于产品范围。

首个正式版本以芝加哥艺术博物馆为核心馆藏，建立未来接入更多博物馆时仍可复用的展示、数据、视觉、动效和 AI 规则。

## 2. Showcase v1 目标

- 建立独立、可识别、适合长期发展的产品品牌。
- 展示芝加哥艺术博物馆中符合图片与权利规则的美术作品，而不局限于三件精选作品。
- 建立可承载大量作品的馆藏浏览、筛选、搜索和详情体验。
- 完成约三个具有可信史料边界的艺术家人格。
- 让 AI 根据统一规则自动生成作品理解入口，而不是逐件人工策展。
- 形成一套有辨识度、可扩展的数字艺术视觉与动效系统。
- 将当前静态 Demo 迁移为可持续开发和公开部署的正式工程。
- 完成稳定性、性能、安全、响应式与项目展示材料。

## 3. 执行原则

1. **真实馆藏优先**：作品事实、图片、权利和来源以馆方及可靠资料为准。
2. **客观呈现优先**：系统提供理解入口，不替用户规定单一叙事或观看顺序。
3. **规则代替手工策展**：描述、问题、观察提示、关联和色板尽量由可复用规则生成。
4. **作品始终是主体**：地图、界面、动效和 AI 都服务于观看，不与作品竞争注意力。
5. **AI 必须可追溯**：明确区分事实、解释、推测与数字化身表达。
6. **设计先行但分阶段精修**：迁移前锁定视觉与动效规则，迁移后基于真实数据完成最终精修。
7. **渐进迁移**：保留当前 Demo 作为视觉和交互基准，不进行无验证的一次性重写。
8. **只展示有权展示的内容**：不得根据艺术家年代推断图片许可。

## 4. Showcase v1 范围

### 4.1 包含范围

- 全球博物馆入口与芝加哥艺术博物馆入口。
- 芝加哥艺术博物馆馆藏的分页浏览、搜索和基础筛选。
- 符合展示规则的作品图片、元数据、权利信息与馆方来源。
- 作品独立页面与可分享链接。
- 高清查看、缩放、拖动、复位和全屏。
- AI 自动生成的作品简介、观察提示、推荐问题、标签、关联和无障碍描述。
- 约三个艺术家人格及其作品上下文对话。
- 回答依据、证据边界和数字化身声明。
- 桌面端最佳体验与可用的移动端体验。
- 项目介绍、品牌分享信息和公开部署。

### 4.2 暂不包含

- 人工逐件策展或人工编排全部观看路径。
- 登录、收藏、评论、社交、付费和用户内容。
- 写实 3D 博物馆复刻。
- 为所有艺术家开放人格对话。
- 复杂的艺术家生涯路线与地点地图。
- 在图片权利不明确时直接展示作品图片。
- 雕塑、立体文物、装置和其他需要三维观看的藏品。
- 为追求数量而接入更多博物馆；Showcase v1 先把芝加哥模式做完整。
