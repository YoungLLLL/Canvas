# Canvium Gallery Showcase v1：视觉与动效系统基准

> 状态：迁移前设计基准，等待三个高风险原型验证  
> 更新日期：2026-07-20  
> 适用范围：首页、全球馆藏入口、馆藏浏览、作品查看器与艺术家人格对话

## 1. 基准结论

批准视觉稿继续作为气质与主要构图参考，但不是可以逐像素照搬的组件规范。Showcase v1 的正式实现必须在大量真实馆藏、长短不一的元数据、双语内容、缺图和异常比例下仍然稳定。

当前确认的方向：

- 严肃、人文、安静，接近博物馆档案与艺术出版物；作品是主要高饱和色彩来源。
- 英文展示标题使用 `Otomanopee One`；它不用于中文，也不强制覆盖所有 `h1`–`h6`。
- 中文标题先使用 `Noto Serif SC`，中文正文与界面使用 `Noto Sans SC`。
- 英文正文与界面先使用 `Inter`。
- 产品完整支持中文和英文，但不是在所有位置同时并排显示两种语言。
- AI 对话的窗口形态尚未锁定；批准稿的右侧单栏只作为候选构图，不作为最终组件形式。

## 2. 颜色

### 2.1 页面颜色

| Token | 数值 | 用途 |
|---|---|---|
| `paper-0` | `#F7F4EE` | 作品页与最浅背景 |
| `paper-1` | `#F1EEE7` | 默认页面背景 |
| `paper-2` | `#DDD7CD` | 图片占位与次级表面 |
| `ink-0` | `#0D0E0D` | 标题与主要操作 |
| `ink-1` | `#343431` | 正文 |
| `ink-2` | `#706D67` | 次级元数据 |
| `line-light` | `rgba(13,14,13,.16)` | 浅色背景分隔线 |
| `graphite-0` | `#111312` | 深色观看空间 |
| `graphite-1` | `#282B29` | 次级深色表面 |
| `text-on-dark` | `#F3EFE7` | 深色背景文字 |
| `accent-bronze` | `#9A7142` | 焦点、选中与今日推荐 |
| `status-error` | `#9B463D` | 错误状态，不作装饰色 |

每件作品可以生成临时色板，但只用于低权重的背景色场和加载占位，不进入全局品牌 Token。

### 2.2 地球颜色与可辨识度

当前 Demo 经过灰度与亮度滤镜后，陆地和海洋过于接近。正式基准改为有明确明度与轻微色温差的双色地图：

| 元素 | 数值 |
|---|---|
| 海洋 | `#101719` |
| 陆地 | `#59584F` |
| 海岸线 | `rgba(224,218,205,.38)` |
| 经纬线 | `rgba(220,224,218,.18)` |
| 普通节点 | `#EEE8DC` |
| 今日推荐 | `#D2A968` |
| 即将开放 | 透明填充＋`#C4C1B9` 描边 |

地球仍保持深石墨气质，但缩小、移动和处于低质量屏幕时也必须一眼分清大陆与海洋。优先使用双色纹理或材质控制，不使用全局 `grayscale()`、`brightness()` 和 `contrast()` 去补救底图。

## 3. 字体与双语

### 3.1 字体职责

| 内容 | 字体 | 建议字重 |
|---|---|---|
| 英文品牌与展示标题 | `Otomanopee One` | 400 |
| 英文正文、导航与元数据 | `Inter` | 400 / 500 |
| 中文标题 | `Noto Serif SC` | 500 |
| 中文正文与界面 | `Noto Sans SC` | 300 / 400 / 500 |

建议 Token：

```css
--font-display-en: "Otomanopee One", sans-serif;
--font-body-en: "Inter", "Helvetica Neue", sans-serif;
--font-display-zh: "Noto Serif SC", "Songti SC", serif;
--font-body-zh: "Noto Sans SC", "PingFang SC", sans-serif;
```

不得再用一个 `--title` 配合 `!important` 同时覆盖中英文标题。混排标题按语言片段指定字体。

基础字号：展示标题桌面 80–128px、移动端 48–64px；页面标题 48–72px；作品标题 28–48px、最多两行；正文 16px/1.7；必要元数据不得低于 12px。

### 3.2 双语策略

- 路由支持稳定语言前缀，例如 `/zh/...` 与 `/en/...`，作品和机构 ID 不随语言变化。
- 提供中文／英文切换并记住用户选择。
- 品牌、机构名、艺术家名和作品原名可以作为标志性双语信息长期共存。
- 导航、按钮、筛选、长正文和对话默认只显示当前界面语言，避免密度翻倍。
- 作品标题优先显示当前语言，下一行可保留馆方原始标题。
- 馆方原始元数据不得被无标识覆盖；系统翻译应保存原文并标记翻译来源。
- AI 对话跟随用户输入语言，也允许用户主动切换；来源保留原文并可提供当前语言摘要。

## 4. 间距、圆角与层级

基础间距刻度：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`。

- 页面水平边距：桌面 48px、平板 32px、移动端 18px。
- 区块间距：64–96px；作品与说明：24–32px；卡片内部：16、24 或 32px。
- 作品本体圆角：0–4px；普通面板：12px；重点玻璃入口：24px；单行操作可使用全圆角。
- 透明玻璃只用于少量关键入口，不扩散到筛选、馆藏资料和版权信息。
- 层级 Token：`base 0`、`sticky 20`、`header 40`、`viewer 60`、`drawer 80`、`modal 100`、`transition 120`、`toast 140`。

## 5. 大量馆藏与图片比例

自动横向作品流只作为博物馆序厅或精选入口，不作为完整馆藏的唯一浏览方式。完整馆藏必须提供搜索、筛选、排序、结果数、分页或虚拟化以及返回状态恢复。

作品比例分为：窄竖版 `<0.67`、竖版 `0.67–0.89`、方形 `0.90–1.10`、横版 `1.11–1.60`、宽幅 `>1.60`。

- 作品查看器始终使用 `contain`，不得裁掉画面。
- 完整馆藏优先采用保持原比例的 justified rows；桌面目标行高 260px，允许 210–320px，间距 20px。
- 超宽与超窄作品限制最大占位，并以中性底板完整展示。
- 比例未知时先保留稳定占位，图片解码后修正时不得产生明显布局跳动。
- 缺图记录使用元数据卡，不伪造图像，也不与有图作品保持同一视觉权重。
- 只有保存了明确焦点坐标的编辑推荐位才允许 `cover` 裁切。

## 6. 动效

| Token | 时长 | 用途 |
|---|---:|---|
| `instant` | 100ms | 按压与焦点 |
| `fast` | 180ms | 悬停、图标与透明度 |
| `base` | 260ms | 筛选与小面板 |
| `medium` | 420ms | 抽屉与对话展开 |
| `slow` | 700ms | 页面构图变化 |
| `shared` | 780ms | 作品共享元素 |
| `max` | 900ms | 地球大尺度重构上限 |

缓动：进入 `cubic-bezier(.22,1,.36,1)`；状态变化 `cubic-bezier(.2,.8,.2,1)`；离开 `cubic-bezier(.4,0,1,1)`；共享元素 `cubic-bezier(.76,0,.24,1)`。

普通内容位移不超过 16px，缩放限制在 `0.98–1.02`。只有地球和作品共享元素允许大尺度缩放。模糊只用于背景色场，不对正文或馆藏缩略图做持续动画。

### 减少动态

`prefers-reduced-motion: reduce` 时停止自动作品流、视差、曲面幕布、共享元素飞行和自动相机移动；地球与页面使用不超过 120ms 的交叉淡入；对话直接改变布局；关闭强制平滑滚动、mandatory scroll snap 和全局滚轮拦截。用户主动缩放或拖动画作仍保留。

## 7. 三个高风险原型

### 7.1 地球转场

验证首页裁切地球到博物馆页右侧地球的连续性、拖动与滚动输入所有权、节点聚合、标签避让、WebGL 回退及减少动态模式。转场不得重建地球或丢失选中机构，最长 900ms。

### 7.2 作品卡转场

验证五类比例、缺图、加载中、虚拟化源卡卸载、窗口尺寸变化以及返回后的筛选、页码、滚动和键盘焦点恢复。正常模式使用 780ms 共享元素；无法找到源卡时安全降级为淡入。

### 7.3 对话展开

对话形态尚未批准。下一轮至少并排比较：编辑侧栏、页边批注、可展开底部抽屉。三种方案都必须保证作品持续可见、不使用普通彩色聊天气泡、数字化身身份和回答依据清晰，并且展开、收起或失败不会重置作品观看状态。

## 8. 当前 Demo 的迁移注意事项

- 合并重复覆盖的画廊、作品页和转场样式，再建立正式 Token。
- 移除英文标题字体对中文标题的全局强制覆盖。
- 移除地球的强制灰度滤镜，按双色材质重新验证。
- 完整馆藏不复制全部作品形成无限循环，也不一次 eager-load 全部缩略图。
- 在对话形态批准前，不把现有右侧栏重构为正式通用组件。
