# Canvium 四页面体验框架

> 状态：思考稿 / 持续扩充  
> 版本：v0.1  
> 更新日期：2026-07-29  
> 适用范围：Canvium 面向用户的核心页面、浏览路径与首页展示方向

## 1. 文档目的

本文用于整理 Canvium 当前的核心页面思路，作为后续产品、设计、动效和工程讨论的共同起点。

目前先明确页面结构与各页面的主要职责，不急于冻结具体视觉风格、动效脚本、技术方案和最终文案。后续产生的新想法、参考案例和设计实验可以继续补充到本文。

## 2. 产品核心体验

Canvium 不是传统的博物馆资料库，也不只是一个 AI 聊天产品。

它希望把以下体验连接起来：

1. 通过具有设计感的展示入口认识产品；
2. 在全球范围发现已经接入的艺术馆；
3. 像逛画廊一样浏览单个艺术馆的大量作品；
4. 靠近并观看一件作品；
5. 在具体作品的上下文中，与对应的 AI 艺术家人格交流。

可以将整体体验概括为：

> 首页负责吸引，地球负责发现，馆藏负责漫游，作品页负责观看与对话。

## 3. 四个核心页面

```text
首页 HOME
 ├─ 探索全球馆藏 → 馆藏地球
 └─ 今日作品 / 人格入口 → 作品详情

馆藏地球 MUSEUM GLOBE
 └─ 选择艺术馆 → 单馆馆藏

单馆馆藏 COLLECTION
 └─ 选择作品 → 作品详情

作品详情 ARTWORK
 ├─ 观看作品
 ├─ 了解作品
 ├─ 与 AI 艺术家人格聊天
 └─ 查看来源与依据
```

### 3.1 首页：品牌展示与体验入口

首页首先是一张展示页。

它未来可以承载更有表现力的页面设计和动效，用来建立 Canvium 的审美、气质和设计能力，并让第一次访问的人快速理解这个网站是做什么的。

首页需要回答三个问题：

- Canvium 是什么？
- 用户可以在这里做什么？
- 用户为什么值得继续探索？

首页的核心内容可以包括：

1. 品牌名称与一句清晰的产品说明；
2. 一件重点作品、今日作品或编辑推荐作品；
3. 与该作品相关的 AI 人格开场或对话提示；
4. “探索全球馆藏”的入口；
5. “直接观看 / 与艺术家对话”的入口。

首页同时支持两条路径：

```text
首页 → 馆藏地球 → 单馆馆藏 → 作品详情
首页 → 作品详情
```

第二条路径很重要。用户不必先经过地球和馆藏，也可以通过首页的重点作品直接进入观看与对话体验。

首页暂时不承担：

- 完整的艺术馆介绍；
- 大量馆藏浏览；
- 复杂搜索和筛选；
- 独立的艺术家资料系统；
- 脱离作品上下文的通用聊天。

### 3.2 馆藏地球：全球艺术馆索引

馆藏地球用于展示 Canvium 已经接入了多少艺术馆，以及这些艺术馆在世界上的位置。

它既是全球馆藏的空间索引，也是进入每个艺术馆馆藏的主要入口。

主要体验包括：

1. 浏览、旋转或缩放地球；
2. 查看已接入艺术馆的地理分布；
3. 选择一个艺术馆；
4. 阅读该艺术馆的简要介绍；
5. 查看地点、接入状态、当前可浏览作品数量等信息；
6. 进入该艺术馆的单馆馆藏页面。

馆藏地球可以包含两个核心页面状态：

| 状态 | 说明 |
|---|---|
| `GLOBE-default` | 展示全球视角和全部已接入艺术馆 |
| `GLOBE-museum-selected` | 聚焦某个艺术馆，同时展示该馆介绍和进入馆藏的动作 |

艺术馆介绍优先放在地球页的选中状态中，不额外建立一个必须经过的单馆介绍页面。

需要继续思考的问题：

- 选中艺术馆是否写入 URL，以支持分享和刷新恢复；
- 多个艺术馆位于同一城市时如何浏览；
- “已开放”“部分开放”“即将接入”等状态如何表达；
- 移动端如何提供与 3D 地球等价的艺术馆列表；
- 地球以真实地理表达为主，还是允许更抽象的艺术化表现。

### 3.3 单馆馆藏：沉浸式作品浏览

单馆馆藏用于浏览某一家艺术馆当前接入 Canvium 的作品。

它首先应该让用户感到自己在“逛画廊”，而不是在操作一个后台数据库。

主要体验包括：

1. 明确当前所在的艺术馆；
2. 大量浏览作品；
3. 保持作品原始比例和视觉节奏；
4. 通过搜索、艺术家、年代或其他条件缩小范围；
5. 选择一件作品进入详情；
6. 从作品详情返回后恢复之前的浏览位置和上下文。

页面建议以作品为主体。搜索和筛选是辅助工具，不应长期占据过多画面空间。

馆藏页暂时不承担：

- 重复一整屏艺术馆品牌介绍；
- AI 人格聊天；
- 复杂的艺术家生涯内容；
- 与当前艺术馆无关的跨馆内容推荐。

需要继续思考的问题：

- 默认采用瀑布流、自由画墙、横向展厅还是其他浏览模型；
- 搜索和筛选是固定显示、抽屉显示还是渐进展开；
- 馆藏量很大时如何兼顾沉浸感和查找效率；
- 是否需要编辑策展路线；
- 如何从地球进入馆藏，并形成具有连续性的页面过渡。

### 3.4 作品详情：观看、理解与 AI 对话

作品详情是 Canvium 最核心的功能页面。

无论用户从首页还是馆藏进入，作品都应始终是页面的第一主体。AI 对话、资料和来源围绕当前作品展开，不能取代或遮蔽观看体验。

页面包含四类核心内容：

1. **观看作品**：高清图像、缩放、拖动、复位和全屏；
2. **了解作品**：标题、艺术家、年代、媒材、尺寸、馆藏信息和观察提示；
3. **AI 人格对话**：与当前作品相关的艺术家数字人格交流；
4. **来源与依据**：馆方记录、图片权利、参考资料和回答依据。

桌面端可以形成“作品观看区 + 上下文面板”的结构：

```text
┌────────────────────────┬──────────────────┐
│                        │  了解作品         │
│                        │  AI 对话          │
│       作品观看器        │  来源与依据       │
│                        │                  │
└────────────────────────┴──────────────────┘
```

右侧上下文可以在“了解”“对话”“来源”之间切换，但切换时不应卸载作品观看器，也不应重置作品的缩放和位置。

移动端可以将右侧上下文转换为底部抽屉、全屏面板或其他适合小屏幕的形态。

AI 对话需要保持以下边界：

- 明确说明这是艺术家的数字化 AI 人格；
- 对话始终绑定当前作品；
- 切换作品时创建新的作品上下文；
- 人格不可用时，作品观看和基础资料仍然可用；
- AI 回答失败不能破坏观看、资料与来源功能。

需要继续思考的问题：

- 首页直接进入时，默认打开观看、介绍还是对话状态；
- 从馆藏进入时是否采用不同的默认状态；
- 对话面板与作品观看区的空间比例；
- 推荐问题、自由输入和 AI 开场如何组织；
- 艺术家人格未完成时如何呈现；
- 作品资料和 AI 解释的视觉边界如何区分。

## 4. 页面关系与导航原则

### 4.1 主导航

在四页面框架下，主导航可以保持精简：

- 首页；
- 探索馆藏；
- 语言切换；
- 搜索入口（是否长期保留待讨论）。

艺术家页面在没有形成完整体验前，不进入正式主导航。

### 4.2 返回关系

- 馆藏地球进入单馆馆藏后，可以明确返回地球；
- 单馆馆藏进入作品详情后，返回时恢复原来的浏览状态；
- 首页直接进入作品详情后，可以返回首页，同时仍提供“所属馆藏”入口；
- 作品详情页不依赖浏览器返回按钮作为唯一出口。

### 4.3 状态保存

- 馆藏搜索、筛选和排序应由 URL 表达；
- 馆藏滚动位置、焦点作品等瞬时状态可以由浏览器历史或 `sessionStorage` 补充；
- 作品观看器的缩放、拖动和面板开合不进入 URL；
- AI 对话内容不进入 URL。

## 5. 建议的正式路由

路由仍需结合现有工程评估后冻结。目前建议：

```text
/{locale}
/{locale}/museums
/{locale}/museums/{museumSlug}/collection
/{locale}/artworks/{artworkKey}
```

分别对应：

| 路由 | 页面 |
|---|---|
| `/{locale}` | 首页 |
| `/{locale}/museums` | 馆藏地球 |
| `/{locale}/museums/{museumSlug}/collection` | 单馆馆藏 |
| `/{locale}/artworks/{artworkKey}` | 作品详情 |

现有或未来的实验页面，例如视觉索引、聊天预览和数据源实验，不参与正式用户路径，应统一归入内部实验区。

## 6. 首页动效的定位

首页可以成为整个项目最有表现力的页面，但目前不冻结具体动效创意。

已确定的原则是：

1. 动效首先服务于品牌和产品理解；
2. 首页可以比其他页面更具实验性；
3. 动效应自然引导至“探索馆藏”或“观看并对话”；
4. 馆藏和作品页优先保证连续浏览、性能和可用性；
5. 不为了展示技术而堆叠互不相关的效果；
6. 动效不能阻止用户立即滚动、点击或跳过；
7. 移动端和减少动态模式需要提供完整的替代体验。

可以继续探索但尚未决定的方向包括：

- 画作局部逐渐显露为完整作品；
- 画作、画框或画布成为页面入口；
- 作品节点与全球地球之间的视觉转化；
- 首页重点作品无缝过渡到作品观看器；
- 版式、文字、坐标和馆藏信息参与动画编排；
- 鼠标视差、空间景深、材质变化或 WebGL 表现；
- 编辑设计、数字博物馆和轻未来感之间的视觉比例。

## 7. 页面动效边界

动效强度可以按照页面职责分层：

| 页面 | 建议动效强度 | 目标 |
|---|---:|---|
| 首页 | 高 | 建立品牌印象、展示设计能力、引导进入核心体验 |
| 馆藏地球 | 中到高 | 强化空间探索和艺术馆发现 |
| 单馆馆藏 | 中 | 营造画廊感，同时保持大量浏览的流畅性 |
| 作品详情 | 低到中 | 让作品保持稳定，重点优化观看和上下文切换 |

页面切换可以形成连续感，但不必全部采用复杂转场：

- 首页重点作品进入作品详情；
- 首页的全球馆藏意象进入馆藏地球；
- 地球上的艺术馆节点进入单馆馆藏；
- 馆藏中的作品卡进入作品观看器。

这些转场目前只作为可能方向，不视为已经确定的实现要求。

## 8. 与当前项目的关系

当前项目已经存在首页、单馆介绍、馆藏、作品详情、艺术家占位页以及若干实验页面。

后续整理时可以重点处理：

1. 将全局地球从单馆介绍中提升为独立的馆藏地球页面；
2. 将单馆介绍合并到地球的艺术馆选中状态；
3. 让单馆馆藏打开后更快进入大量作品浏览；
4. 保留首页直接进入作品详情和 AI 对话的路径；
5. 暂停独立艺术家页面，不将占位页面放入正式导航；
6. 将实验性页面与正式页面分离；
7. 将作品详情中的观看器、资料、对话和来源逐步拆分为独立模块；
8. 正确区分真实艺术馆与 Europeana 等聚合数据来源。

在具体重构前，需要保护当前工作区已有的未提交修改，并分阶段迁移，避免一次性移动大量页面和组件。

## 9. 暂不决定的事项

以下事项保持开放：

- 首页最终视觉风格；
- 首页具体动效脚本；
- 是否使用完整的滚动叙事；
- 馆藏地球的真实程度与艺术化程度；
- 单馆馆藏的最终浏览模型；
- 首页重点作品和今日作品的选取机制；
- 首页直接进入作品详情时的默认面板；
- 是否建设独立艺术家页面；
- 全站搜索的位置与作用；
- 跨艺术馆搜索是否属于当前阶段；
- 多数据源如何映射到真实艺术馆；
- 页面之间采用何种连续转场；
- WebGL、GSAP、View Transitions 等技术的具体分工。

## 11. 当前共识摘要

现阶段已经形成的核心共识：

- 产品围绕四个核心页面展开；
- 首页负责展示、定调和分发入口；
- 馆藏地球负责全球艺术馆发现与介绍；
- 单馆馆藏负责大量、沉浸式的作品浏览；
- 作品详情负责观看、理解、AI 人格对话和来源；
- 首页既能进入馆藏地球，也能直接进入作品详情；
- 首页未来可以重点升级视觉和动效，但具体方案继续思考；
- 暂时不急于冻结表现形式或立即进行大规模代码重构。
