# Canvium 艺术家人格候选评分表 v0.1

更新日期：2026-07-24

## 1. 结论

建议首批进入完整人格试作的三位艺术家是：

1. Vincent van Gogh
2. Claude Monet
3. Mary Cassatt

这不是最终发布名单。三人仍须分别完成“20 个事实题、10 个边界题、3 件作品上下文问答”的最小证据试作，全部通过硬门槛后才能发布。

首位候补为 Paul Cézanne；若 Cassatt 的书信定位或中译维护成本在试作中超出项目能力，则用 Cézanne 替换。Berthe Morisot 为第二候补。

## 2. 评估口径

评分沿用《Canvas 作品内容增强与艺术家人格 Schema v0.1》第 10 节：

- 每个维度按 0–5 分评估，再乘以权重换算为百分制。
- 总分达到 75，且“第一手材料质量”和“人格证据充分度”均不低于 4/5，才进入完整试作池。
- 馆藏覆盖是当前产品查询条件下的可用作品数，不等同于博物馆拥有的全部作品数。
- “风险可控性”分数越高代表风险越可控。
- 尚未执行最小证据试作的候选只能标为“有条件通过”，不能标为可发布。

当前 AIC 覆盖数来自 2026-07-24 对项目 `/api/catalog` 的审计，条件为公共领域、绘画、当前有可展示图像。结果应在馆藏同步或查询规则变化后重算。

## 5. 为什么推荐这三人

### Vincent van Gogh

- 优势：书信材料完整、可检索、时间跨度长；作品、地点、创作方法和情绪表达之间有大量可核对连接。
- 可辨声线：认真、直接、关系导向，常从颜色、劳动和观察谈起。
- 风险：最容易被扁平化为“疯狂天才”；不得进行医学诊断，不得把创作句子伪装成原信引语。

### Claude Monet

- 优势：AIC 覆盖最强，已有较成熟的本地证据包；适合围绕光线、天气、时间和反复工作形成作品导向的对话。
- 可辨声线：精确、克制、关注条件变化与观看过程。
- 风险：不能把“捕捉瞬间”写成轻松即兴；需要保留其持续修改、安排展览和处理职业事务的一面。

### Mary Cassatt

- 优势：史密森尼保存并数字化了可逐项查看的书信；与 Monet、Van Gogh 相比，她能带来不同的职业处境、社交网络和对现代日常生活的观察。
- 可辨声线：独立、务实、对人物关系和画面组织敏锐，但不使用“强势女性”之类模板化标签。
- 风险：AIC 可用作品仅 3 件，首轮必须围绕这 3 件作品验证上下文密度；不可把后来评论者对女性身份的解释冒充她本人观点。

## 6. 组合层面的取舍

Monet 与 Van Gogh 都来自十九世纪欧洲绘画语境，单看人口统计并不够分散。保留这两人的原因是他们的第一手材料质量、AIC 覆盖和作品连接能力显著领先，而且可形成不同的对话重心：

- Monet：环境条件、系列工作、反复观看。
- Van Gogh：颜色与劳动、人与人的关系、阅读和自我反省。
- Cassatt：人物互动、现代生活、职业判断与社会空间。

首批不追求“每个人都来自完全不同的时代”，而是优先验证三种证据充足、能被同一评估体系区分的声音。第二批应优先补足非欧洲或更早时期的艺术语境，但前提仍是人格证据达到硬门槛。

## 8. 下一步

1. 为推荐三人各建立可机器校验的 v2 人格包。
2. 为每人建立 20 个事实题、10 个边界题和至少 3 件作品上下文题。
3. 先用确定性规则执行引用完整性、时间边界、禁诊断、禁伪引语和跨作品证据污染检查。
4. 在不使用 API Key 的阶段完成本地备用开场、降级回答和人格披露。
5. 有 Key 后再运行模型回答质量与人格区分度评审；模型评审不能替代硬规则。
