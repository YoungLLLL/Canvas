# Canvium Gallery Showcase v1：信息架构与页面状态规范

> 状态：阶段 2 执行基准  
> 版本：v1.0  
> 更新日期：2026-07-20  
> 适用范围：Showcase v1 的首页、博物馆、馆藏、作品与艺术家页面

## 1. 文档目的

本文冻结 Showcase v1 的页面边界、稳定路由、浏览状态、异常状态和响应式功能差异，作为视觉设计、Next.js 工程、数据接口和浏览器测试的共同依据。

本文只定义信息架构和行为契约，不锁定阶段 3 尚待比较的 AI 对话窗口形态，也不替代馆藏权利规则、视觉 Token 或 AI 内容 Schema。

## 2. 核心决策

1. 主路径为“首页 → 博物馆 → 馆藏 → 作品”，四者均可独立访问；博物馆介绍与完整馆藏不再压在同一个页面状态中。
2. 艺术家页只为已经完成资料审核并正式发布的人格开放；普通馆藏艺术家名称仍可用于筛选，但不自动获得人格页。
3. 中文和英文使用稳定语言前缀。作品、机构和艺术家标识不随语言变化。
4. 馆藏查询由 URL 完整表达；返回馆藏时恢复查询、页码、滚动位置和键盘焦点。
5. 对话、依据和来源属于作品上下文，不建立脱离作品的聊天页；对话记录不写入 URL，也不默认跨作品保留。
6. 首页地球选择、查看器缩放、抽屉开合等瞬时状态不建立独立内容路由。
7. Showcase v1 只公开符合阶段 1 规则的二维绘画。界面使用“当前可浏览范围”等准确表述，不宣称完整收录 ARTIC 全部馆藏。
8. 桌面端与移动端保持相同的信息和核心动作；移动端可以降低空间动效和改变面板形态，但不能删掉搜索、筛选、权利、来源或 AI 边界。

## 3. 页面与路由

### 3.1 路由表

| 页面代码 | 页面 | 稳定路由 | 主要职责 |
|---|---|---|---|
| `HOME` | 首页／全球入口 | `/{locale}` | 品牌、今日作品、全球博物馆入口 |
| `MUS` | 博物馆页 | `/{locale}/museums/{museumSlug}` | 机构介绍、收录边界、馆藏入口 |
| `COL` | 馆藏页 | `/{locale}/museums/{museumSlug}/collection` | 浏览、搜索、筛选、排序和分页 |
| `ART` | 作品页 | `/{locale}/artworks/{artworkKey}` | 高清观看、资料、AI 对话与来源 |
| `ARI` | 艺术家页 | `/{locale}/artists/{artistSlug}` | 已发布人格说明、史料边界和相关作品 |

Showcase v1 的合法 `locale` 为 `zh`、`en`。示例：

```text
/zh
/zh/museums/art-institute-of-chicago
/zh/museums/art-institute-of-chicago/collection?q=monet&from=1880&to=1900&sort=relevance&page=2
/zh/artworks/artic-28560
/zh/artists/claude-monet
```

### 3.2 标识规则

- `museumSlug` 和 `artistSlug` 使用稳定英文小写 kebab-case；名称翻译变化不得改变 slug。
- `artworkKey` 使用 `{provider}-{sourceId}`，例如 `artic-28560`，避免未来多馆接入时 ID 冲突。
- 路由不得使用作品标题作为唯一标识。标题变化或翻译变化不应使旧链接失效。
- 当前唯一正式馆藏源为 ARTIC；路由结构仍保留多馆扩展能力。
- 老链接或未来别名应以永久重定向指向唯一规范路由，不复制页面。

### 3.3 语言规则

- 首次访问无语言前缀的 `/` 时，根据已保存选择决定语言；没有记录时使用浏览器语言，其他情况回退 `en`。
- 跳转后地址栏必须出现语言前缀，服务端输出对应语言的 canonical 与 alternate language 链接。
- 切换语言只替换 `locale`，保留资源 ID、馆藏查询参数和当前页面语义。
- 用户界面、筛选和长正文只显示当前语言；机构正式名、艺术家原名、作品原题等可按双语规则共存。

## 4. 全站导航与页面关系

全局页头固定提供：主页、博物馆／馆藏入口、搜索入口、语言切换。页面内面包屑提供资源层级，不把浏览器返回按钮当作唯一返回方式。

```text
HOME
  → MUS
      → COL
          → ART
              → COL（恢复离开前状态）
              → ARI（仅已发布人格）
                  → ART

HOME → ART（今日作品快捷入口）
HOME → COL（首页搜索快捷入口）
```

跳转约束：

- 从馆藏卡进入作品页时携带内部返回上下文，但作品 URL 本身保持干净、可独立分享。
- 直接打开作品链接时，“返回馆藏”回到该作品所属博物馆的默认馆藏页。
- 从艺术家页进入作品页时，“返回”优先交给浏览器历史；作品页始终另有明确的“所属馆藏”链接。
- 外部馆方网站在新标签页打开，并清楚标记为外部链接。

## 5. HOME：首页／全球入口

### 5.1 内容结构

1. 品牌与一句话说明。
2. 今日作品及直接进入作品页的动作。
3. 艺术家对话入口；只有今日作品对应人格已发布时出现，否则替换为观察提示。
4. 全球博物馆索引；桌面端以地球为主交互，所有设备都必须有等价的可访问机构列表。
5. 当前选中博物馆的简介、开放状态和进入博物馆页的动作。
6. 数据来源与产品边界简述。

### 5.2 页面状态

| 状态 | 行为 |
|---|---|
| `HOME-ready` | 今日作品和博物馆入口可用；地球不是唯一导航方式。 |
| `HOME-museum-selected` | 显示所选机构摘要；选择属于瞬时状态，不改变 canonical URL。 |
| `HOME-daily-unavailable` | 今日作品获取失败时保留品牌与博物馆入口，使用稳定编辑占位文案，不伪造作品。 |
| `HOME-globe-fallback` | WebGL 不可用、减少动态或低性能设备使用静态地图／机构列表。 |

首页不承担完整馆藏浏览。点击“探索馆藏”先进入 `MUS`，其主要动作再进入 `COL`；今日作品可以直接进入 `ART`。

## 6. MUS：博物馆页

### 6.1 内容结构

1. 机构正式名、所在地、馆方简介和官方网站。
2. Canvium 当前收录范围：二维绘画、图片与权利条件、数据更新时间。
3. 代表作品或可选序厅式作品流；它不是完整结果集。
4. 当前可浏览结果的动态数量，不硬编码馆藏总数。
5. “浏览馆藏”主动作，进入该馆默认 `COL`。
6. 馆方数据、图片许可与 Canvium 处理方式的简明说明。

### 6.2 页面状态

| 状态 | 行为 |
|---|---|
| `MUS-ready` | 机构资料与馆藏入口均可用。 |
| `MUS-partial` | 机构资料可用、代表作品失败；仍允许进入馆藏。 |
| `MUS-collection-unavailable` | 馆藏暂不可用；保留机构资料、说明和重试，不展示虚假计数。 |
| `MUS-coming-soon` | 仅用于未来已收录但尚未开放的机构；不显示可用馆藏动作。 |
| `MUS-not-found` | 未知 slug 返回本地化 404，并提供返回首页入口。 |

博物馆页不保存搜索条件，也不重复完整筛选控件。

## 7. COL：馆藏页

### 7.1 内容结构

1. 博物馆名称、收录范围和动态结果数。
2. 搜索框。
3. 基础筛选：艺术家、创作年代、图片可用性。
4. 排序。
5. 已应用条件与逐项清除／全部清除。
6. 保持作品原比例的结果网格；缺图记录使用低权重资料卡。
7. 分页与当前范围说明。

Showcase v1 不把横向自动作品流作为完整馆藏的唯一浏览方式。

### 7.2 URL 查询契约

| 参数 | 格式与默认值 | 说明 |
|---|---|---|
| `q` | 去除首尾空格的 UTF-8 文本；默认空 | 匹配作品标题、艺术家及馆方可搜索字段 |
| `artist` | ARTIC 艺术家 ID；可重复 | 多个值使用 OR；不同筛选组之间使用 AND |
| `from` | 四位年份；可省略 | 创作年份下界 |
| `to` | 四位年份；可省略 | 创作年份上界 |
| `availability` | `image`、`metadata`、`all`；默认 `image` | 默认只看可合法展示图片的记录 |
| `sort` | `relevance`、`recent`、`title-asc`、`date-asc`、`date-desc` | 有 `q` 时默认 `relevance`，否则默认 `recent` |
| `page` | 从 1 开始的正整数；默认 1 | 直接对应可分享分页；默认值不写入规范 URL |

隐含且不可关闭的准入条件为：ARTIC `Painting`、公共领域、无权利冲突；`metadata` 只放宽“必须有可展示图片”，不放宽作品类型或权利规则。

查询行为：

- 输入搜索词后提交，或停止输入 400ms 后执行；输入法组合期间不得请求。
- 改变 `q`、筛选或排序时将 `page` 重置为 1。
- 翻页产生一条浏览器历史记录；快速输入产生 `replaceState`，已提交查询和筛选产生 `pushState`。
- 无效参数被忽略并在规范化 URL 中移除；`from > to` 时不请求数据，直接显示字段级错误。
- 参数输出顺序固定为 `q`、`artist`、`from`、`to`、`availability`、`sort`、`page`，便于缓存、分享和测试。
- 搜索结果到达 ARTIC 10,000 条可访问边界时，明确说明当前可浏览边界，不制造还能继续翻页的链接。

### 7.3 返回状态恢复

URL 是查询、筛选、排序和页码的唯一事实来源。浏览器历史和 `sessionStorage` 只补充以下瞬时状态：

- 离开前的垂直滚动位置；
- 打开的作品卡 `artworkKey`；
- 键盘焦点所在卡片；
- 已经加载且仍在短期缓存内的页数据。

从 `ART` 返回 `COL` 时：

1. 先按原 URL 恢复结果；
2. 若目标卡仍存在，滚动至离开前位置并把焦点还给该卡；
3. 若目标卡因数据更新消失，恢复相同查询并把焦点放到结果标题，同时说明结果已更新；
4. 直接访问、刷新或跨设备分享只保证恢复 URL 可表达的状态，不保证滚动位置。

### 7.4 页面状态

| 状态 | 触发与表现 | 可用动作 |
|---|---|---|
| `COL-initial-loading` | 首次请求；显示稳定比例骨架，不显示伪造作品色彩 | 返回博物馆 |
| `COL-refreshing` | 已有结果上改变条件；旧结果降权并标记更新中，避免整页闪烁 | 继续浏览已显示内容、取消过期请求 |
| `COL-ready` | 显示结果数、范围、网格和分页 | 搜索、筛选、排序、打开作品 |
| `COL-empty-query` | 条件合法但无结果 | 清除单项／全部条件、返回默认馆藏 |
| `COL-empty-source` | 当前数据范围没有合格记录 | 查看收录规则、返回博物馆 |
| `COL-error` | 上游失败且无可接受缓存 | 重试、返回博物馆；不把错误伪装为空结果 |
| `COL-stale` | 上游失败但有可接受的短期旧缓存 | 浏览旧结果、重试，并显示数据时间 |
| `COL-offline-cached` | 离线且本地有当前页缓存 | 浏览当前页；禁用会请求新数据的翻页并解释原因 |
| `COL-offline-empty` | 离线且无缓存 | 重试、返回已缓存页面或首页 |
| `COL-page-invalid` | 页码超过当前总页数 | 重定向至最后有效页；若总数未知则回第 1 页并提示 |

图片单项失败不升级为整页错误：卡片转为资料卡，并提供进入作品资料页的动作。

## 8. ART：作品页

### 8.1 内容关系

作品页只有一个页面路由，内部按以下优先级组织：

1. **观看**：作品图像、缩放、拖动、复位、全屏和无障碍替代文本，是始终保留的第一主体。
2. **资料**：标题、艺术家、年代、媒材、尺寸、馆藏编号与作品说明。
3. **理解入口**：AI 生成简介、观察提示和推荐问题，标记其生成性质与更新时间。
4. **对话**：只在该艺术家人格已发布且当前服务可用时开放；始终绑定当前作品。
5. **来源与权利**：馆方记录、credit line、图片许可、事实／解释／推测标记和回答依据。

资料、对话和来源不能遮挡或卸载观看器。桌面端可并列，移动端可使用底部抽屉；切换它们不得重置缩放、位置、全屏退出后的焦点或对话上下文。

### 8.2 URL 与瞬时状态

- `#details`、`#dialogue`、`#sources` 可作为页面内可分享锚点；无锚点时聚焦观看区。
- 查看器缩放、平移、全屏、来源抽屉开合和未提交文本不写入 URL。
- 对话内容不进入 URL、页面元数据或分析事件正文。
- 切换作品必须进入新的作品路由并创建新的对话上下文；不把上一件作品的问答当作当前作品证据。

### 8.3 页面状态

| 状态 | 行为 |
|---|---|
| `ART-loading` | 先呈现稳定观看区与元数据骨架；图片和增强内容独立加载。 |
| `ART-ready` | 图片、基础资料与来源可用；AI 能力按发布状态出现。 |
| `ART-image-loading` | 显示低清预览／作品色板占位，解码后渐进替换。 |
| `ART-image-error` | 不显示伪图；保留元数据、权利说明、馆方链接与重试。 |
| `ART-metadata-only` | 记录合法但没有可展示图片；明确说明原因，隐藏缩放控件。 |
| `ART-content-pending` | 基础资料可用，AI 增强内容尚未发布；使用本地稳定观察引导。 |
| `ART-ai-unavailable` | 保留观看、资料、预生成内容和推荐问题；禁用实时发送并解释可稍后重试。 |
| `ART-ai-error` | 仅当前回答失败；保留历史对话、草稿和观看状态，提供重试。 |
| `ART-offline` | 已缓存图片／资料继续可看；实时对话禁用，馆方外链保留。 |
| `ART-rights-withdrawn` | 不再返回或显示图片；说明展示状态已更新并保留允许公开的元数据。 |
| `ART-not-found` | 未知、类型不合格或不可公开记录返回 404；不泄露隔离原因。 |

### 8.4 对话边界

- 页面必须标明“艺术家数字化身”，不得让用户误认为在与真实人物或馆方交谈。
- 回答中的依据在当前作品页展开；来源条目可链接至馆方或可靠外部资料。
- 人格未发布时不显示自由输入框；推荐问题可作为预生成理解入口，但不得伪装成人格回答。
- AI 请求失败不影响作品、资料、权利和来源区域。

## 9. ARI：艺术家页

### 9.1 内容结构

1. 艺术家姓名、原文名、生卒年份和简要生平。
2. “数字化身”声明、人格版本、资料范围和不确定性边界。
3. 第一手材料、可靠研究资料与馆方来源概览。
4. ARTIC 当前可浏览的相关绘画入口。
5. 可选的示例问题；对话仍在具体作品页发生。

Showcase v1 不实现复杂生涯路线、地点地图或脱离作品上下文的通用聊天。

### 9.2 页面状态

| 状态 | 行为 |
|---|---|
| `ARI-ready` | 人格已发布，资料边界和相关作品均可查看。 |
| `ARI-related-empty` | 人格资料可用，但当前馆藏范围没有合格作品；不开放无作品上下文对话。 |
| `ARI-partial` | 人格资料可用、相关作品请求失败；保留资料与重试。 |
| `ARI-not-found` | 未发布、撤回或未知人格统一返回 404；候选人格不可被索引。 |

## 10. 全局系统状态

### 10.1 加载

- 页面导航先保留现有页面，目标页准备好后再切换；长于 300ms 才显示显式加载反馈。
- 骨架必须反映最终布局和作品比例，避免明显布局跳动。
- 图片、基础元数据、AI 增强内容和实时对话分别管理状态，不能因次级内容失败阻塞整页。
- 请求切换后取消或忽略旧响应，禁止旧搜索结果覆盖新条件。

### 10.2 空结果与错误

- “没有匹配结果”只用于成功完成且返回零项的合法请求。
- 网络失败、上游限流、超时、Schema 校验失败和服务端异常使用错误状态。
- 错误文案包含发生了什么、哪些内容仍可使用、用户下一步能做什么；不直接暴露堆栈、上游查询或内部判定细节。
- 全局 toast 只确认轻量动作，不承载必须阅读的错误和权利信息。

### 10.3 无网络

- 监听实际请求结果，不只依赖 `navigator.onLine`。
- 已经打开的合法图片与资料可由缓存继续显示；不得为离线体验长期保留已撤回权利的图片。
- 所有需要网络的动作保持可见但进入解释性禁用／失败状态，避免用户误以为功能不存在。
- 恢复网络后不自动发送用户未成功提交的 AI 问题，由用户确认重试。

### 10.4 AI 不可用

AI 是作品理解的增强能力，不是浏览馆藏的前置条件。不可用时至少保留：

- 作品查看器和完整基础资料；
- 已发布且仍有效的预生成简介、观察提示、推荐问题和无障碍描述；
- 来源、权利和数字化身边界说明；
- 清晰的实时对话不可用状态。

不得用本地固定文本伪装成刚刚生成的实时回答。

### 10.5 404 与不可公开记录

- 未知页面显示本地化 404。
- 作品存在但不属于二维绘画、权利受限或处于隔离状态时，公开页面统一按不可访问处理。
- 旧链接对应已撤回图片时，可在仍允许公开元数据的前提下进入 `ART-rights-withdrawn`；否则返回 404。

## 11. 桌面端与移动端

断点由阶段 3 Token 最终确定；本节只冻结能力差异。

| 能力 | 桌面端 | 移动端 |
|---|---|---|
| 全球入口 | 可交互地球＋机构列表 | 轻量静态地图／机构列表；不要求 WebGL |
| 馆藏筛选 | 常驻侧栏或顶部组合区 | 底部筛选面板；关闭后以已应用条件摘要呈现 |
| 结果布局 | justified rows，保留原比例 | 单列或双列自适应，完整图片优先 |
| 作品观看 | 观看器与资料／对话可并列 | 观看器优先；资料、对话、来源用分段内容或底部抽屉 |
| 图片操作 | 滚轮／按钮缩放、拖动、键盘、全屏 | 双指缩放、拖动、按钮复位、系统全屏可用时开放 |
| 对话 | 形态由阶段 3 原型决定 | 不覆盖整幅作品；键盘弹出后仍可返回观看 |
| 动效 | 可使用共享元素和地球连续转场 | 缩短并减少大尺度转场；遵守减少动态设置 |
| 权利与来源 | 完整显示 | 内容相同，可折叠但不能省略 |

移动端不提供悬停专属操作。所有悬停信息都必须能通过点击、焦点或常驻文本获得。横竖屏切换不得丢失馆藏查询、作品观看位置之外的页面状态或对话历史。

## 12. 可访问性与焦点恢复

- 所有核心流程可用键盘完成；地球之外始终提供语义化机构列表。
- 页面导航后焦点进入新页面 `h1`；返回馆藏时按第 7.3 节恢复到原作品卡。
- 抽屉和模态层打开时管理焦点范围，关闭后回到触发按钮。
- 作品图片使用馆方 alt text；没有馆方文本时使用已审核的无障碍描述，并标明生成来源。
- 加载、结果数变化、错误和 AI 回答完成使用克制的 live region 通知。
- 减少动态模式不改变信息结构和完成任务的能力。

## 13. 页面标题与分享语义

| 页面 | 标题模板 |
|---|---|
| `HOME` | `Canvium Gallery — {localizedTagline}` |
| `MUS` | `{museumName} — Canvium Gallery` |
| `COL` | `{museumName} Collection — Canvium Gallery` |
| `ART` | `{artworkTitle} — {artistName} — Canvium Gallery` |
| `ARI` | `{artistName} — Canvium Gallery` |

- 馆藏查询页的 canonical 包含有意义的查询与筛选，但移除默认值和无效参数。
- 作品分享卡使用有权展示的图片；无图或权利撤回时使用品牌分享图。
- 对话内容、搜索框未提交文本和个人浏览状态不进入页面标题或分享元数据。

## 14. 阶段 4／5 验收接口

实现时至少覆盖以下浏览器测试：

1. `HOME → MUS → COL → ART → 返回 COL` 恢复 URL、页码、滚动和焦点。
2. 复制馆藏筛选 URL 到新窗口后得到相同查询语义。
3. 浏览器前进／后退不会重复请求旧条件或丢失已提交状态。
4. 中英文切换保留当前资源与查询。
5. 搜索空结果、上游错误、旧缓存、离线无缓存具有不同画面和动作。
6. 单张图片失败不使馆藏页整体失败。
7. AI 不可用不阻塞作品观看、资料、权利和来源。
8. 未发布人格和不可公开作品不能通过猜测 URL 访问。
9. 桌面与移动端均可完成搜索、筛选、翻页、查看权利、打开来源和返回馆藏。
10. 减少动态模式下所有导航和状态恢复仍然成立。
