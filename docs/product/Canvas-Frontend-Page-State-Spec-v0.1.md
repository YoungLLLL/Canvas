# Canvas 前端页面与状态规范 v0.1

## 1. 文档目的

本文件用于冻结 Canvas MVP 的前端页面边界、页面内关键状态和页面之间的跳转关系，作为低保真设计、高保真设计、Figma Prototype 与后续前端开发的共同依据。

本版只讨论桌面端核心体验，不讨论正式工程架构。

## 2. 本轮设计约束

- 设计基准尺寸：桌面端 `1440 × 960`。
- 首期只开放芝加哥艺术博物馆。
- 首期只包含三件梵高作品：《卧室》《自画像》《诗人的花园》。
- 对话使用推荐问题、固定回答与边界提示，不接入真实 AI。
- 地图缩放、信息卡、热点、对话和来源面板均属于页面内状态，不建立独立路由。
- 艺术家人生路线只制作概念体验，不扩展为完整内容系统。

## 3. 路由页面

| 页面代码 | 页面 | 路由 | MVP 定位 |
|---|---|---|---|
| `MAP` | 全球博物馆地图 | `/` | 完整页面 |
| `GAL` | 芝加哥艺术博物馆数字画廊 | `/museum/chicago-art-institute` | 完整页面 |
| `ART` | 单件作品观看 | `/artwork/[artworkId]` | 核心页面 |
| `ARI` | 梵高人生路线 | `/artist/van-gogh` | 概念页面 |

MVP 共 4 个路由页面。其中 `MAP → GAL → ART` 是完整主路径，`ARI` 是作品观看后的延伸路径。

## 4. 必须设计的关键状态

### 4.1 MAP：全球博物馆地图

#### MAP-01 全球默认状态

- 全球地图是页面主体。
- 显示已开放城市地标。
- 显示每日艺术推荐入口。
- 显示博物馆、艺术家、每日艺术和搜索入口。
- 用户能在没有说明的情况下识别芝加哥可以点击。

主要动作：

- 点击芝加哥 → `MAP-02`。
- 点击每日艺术 → 直接进入对应 `ART-01`。

#### MAP-02 芝加哥选中状态

- 地图镜头聚焦芝加哥。
- 显示城市名称、开放博物馆数量和代表作品。
- 芝加哥艺术博物馆成为下一层主要入口。

主要动作：

- 点击芝加哥艺术博物馆 → `MAP-03`。
- 点击地图空白或返回 → `MAP-01`。

#### MAP-03 博物馆信息卡状态

- 保持当前博物馆地标可见。
- 展示博物馆名称、位置、开放作品数量、代表作品缩略图和馆藏说明。
- “进入数字画廊”是唯一高强调主按钮。

主要动作：

- 点击“进入数字画廊” → `GAL-01`。
- 关闭信息卡 → `MAP-02`。

### 4.2 GAL：数字画廊

#### GAL-01 画廊默认状态

- 三件作品以横向空间关系展示。
- 一件作品位于中央，具有最高视觉权重。
- 两侧作品仍然可识别为可点击对象。
- 显示当前博物馆和中央作品的基础信息。

主要动作：

- 点击侧边作品 → `GAL-02`。
- 点击中央作品 → `GAL-03`。
- 返回地图 → `MAP-03`。

#### GAL-02 作品切换状态

- 被点击的侧边作品平滑移动到中央。
- 原中央作品移动到侧边并降低视觉权重。
- 标题、年份等信息同步更新。
- 该状态仍然停留在当前画廊路由。

主要动作：

- 再次点击中央作品 → `GAL-03`。
- 继续点击其他侧边作品 → 更新当前中央作品。

#### GAL-03 走近作品过渡状态

- 作为画廊到作品页之间的动画关键帧，不建立独立路由。
- 画廊背景和其他作品降低视觉权重。
- 中央作品逐渐成为画面主体。
- 艺术家数字化身和观看控件在动画末段出现。
- 减少动态模式使用淡入替代。

主要动作：

- 动画结束 → 对应作品的 `ART-01`。

### 4.3 ART：单件作品观看

#### ART-01 默认观看状态

- 作品是页面第一视觉主体。
- 支持缩放、拖动、复位和全屏。
- 默认不显示热点。
- 显示作品基础资料和来源入口。
- 梵高数字化身保持安静。
- 显示推荐问题，但不主动播放回答。

主要动作：

- 点击“探索细节” → `ART-02`。
- 点击推荐问题或输入问题 → `ART-04`。
- 返回画廊 → `GAL-01`，并恢复当前作品为中央作品。

#### ART-02 探索细节状态

- 在作品上显示 3～6 个热点。
- 热点不能压过作品本身。
- 明确提供退出探索细节的动作。

主要动作：

- 点击热点 → `ART-03`。
- 关闭探索细节 → `ART-01`。

#### ART-03 细节聚焦状态

- 作品自动缩放并定位到所选细节。
- 当前热点高亮，其他热点降低视觉权重。
- 显示与该细节相关的观察提示和推荐问题。
- 不自动讲解。

主要动作：

- 点击推荐问题 → `ART-04`。
- 返回完整画面 → `ART-02`。

#### ART-04 艺术家对话状态

- 用户问题与艺术家回答在固定区域内左右区分。
- 回答尽量引用当前画面细节。
- 回答结尾引导用户重新观察作品。
- 对话不覆盖作品的关键区域。

主要动作：

- 继续提问 → 保持 `ART-04`，对话区域内部滚动。
- 点击回答旁“依据” → `ART-05`。
- 回到画面缩放或点击热点 → 保持当前作品页和对话上下文。

#### ART-05 来源面板状态

- 以抽屉或轻量面板覆盖在作品页上，不建立独立路由。
- 显示馆藏页面、书信或研究资料。
- 明确区分事实、学术解释和合理推测。
- 关闭后恢复之前的观看或对话位置。

主要动作：

- 关闭来源面板 → 返回进入前的 `ART` 状态。

#### ART-06 观展结束分流状态

- 用户已完成至少一次“观看—提问—重新观看”循环后出现。
- 同时提供两条明确路径：继续逛博物馆、跟随艺术家。
- 两条路径具有不同的内容预期，不使用模糊文案。

主要动作：

- “继续逛博物馆” → `GAL-01`，恢复当前作品位置。
- “跟随艺术家” → `ARI-01`。

### 4.4 ARI：梵高人生路线

#### ARI-01 路线概览状态

- 展示荷兰、巴黎、阿尔勒、圣雷米和奥维尔。
- 使用时间、地点和作品建立路线关系。
- 明确这是艺术家探索体系，而不是另一个博物馆地图。
- 第一阶段不要求自由缩放和完整搜索。

主要动作：

- 点击城市或创作阶段 → `ARI-02`。
- 返回上一件作品 → `ART-01`。

#### ARI-02 创作阶段选中状态

- 展示地点、时间、创作阶段和当地代表作品。
- 代表作品卡是主要后续动作。

主要动作：

- 点击代表作品 → 对应作品的 `ART-01`。
- 关闭阶段信息 → `ARI-01`。

## 5. 暂不单独制作的页面

以下内容在 MVP 中不建立独立路由：

- 城市详情页：使用地图聚焦状态和城市信息卡表达。
- 博物馆详情页：使用地图中的博物馆信息卡表达。
- 每日艺术页：推荐卡直接进入作品观看页。
- 对话页：对话集成在作品观看页。
- 来源页：来源使用抽屉或轻量面板。
- 搜索结果页：MVP 只保留简化搜索入口或搜索浮层。
- 登录、收藏、历史和个人中心：后续版本。

## 6. 首轮 Figma 画板清单

首轮共制作 14 张桌面画板：

| 顺序 | 画板名称 |
|---|---|
| 01 | `MAP-01 — 全球默认` |
| 02 | `MAP-02 — 芝加哥选中` |
| 03 | `MAP-03 — 博物馆信息卡` |
| 04 | `GAL-01 — 画廊默认` |
| 05 | `GAL-02 — 作品切换` |
| 06 | `GAL-03 — 走近作品结束帧` |
| 07 | `ART-01 — 默认观看` |
| 08 | `ART-02 — 探索细节` |
| 09 | `ART-03 — 细节聚焦` |
| 10 | `ART-04 — 艺术家对话` |
| 11 | `ART-05 — 来源面板` |
| 12 | `ART-06 — 观展结束分流` |
| 13 | `ARI-01 — 路线概览` |
| 14 | `ARI-02 — 创作阶段选中` |

所有画板使用 `页面代码-状态编号 — 中文状态名` 命名，不再使用容易与 PRD 原型编号混淆的单独 `P01/P04` 命名。

## 7. 后续补充但不阻塞首轮设计的状态

- 首次使用气泡引导。
- 地图、图片和对话加载状态。
- 外部图片加载失败状态。
- 搜索浮层。
- 语音开启、关闭和播放状态。
- 全屏作品观看状态。
- 空状态与通用错误状态。
- 减少动态模式的具体视觉表现。

## 8. 页面状态总流程

```text
MAP-01
  → MAP-02
  → MAP-03
  → GAL-01
  ↔ GAL-02
  → GAL-03
  → ART-01
      ↔ ART-02
      ↔ ART-03
      → ART-04
      ↔ ART-05
      → ART-06
          → GAL-01
          → ARI-01
              ↔ ARI-02
              → ART-01
```

每日艺术入口形成一条快捷路径：

```text
MAP-01 → ART-01
```

## 9. 冻结前需要确认的产品判断

- [ ] 城市与博物馆不拆成独立页面，只作为地图状态。
- [ ] 每日艺术不拆成独立页面，直接进入作品页。
- [ ] 对话、来源和结束分流全部集成在作品页。
- [ ] 艺术家路线首期只做路线概览与阶段选中两个状态。
- [ ] 首轮按 14 张桌面画板设计，系统状态后补。
- [ ] Figma 统一改用 `MAP/GAL/ART/ARI` 命名体系。
