# Canvas 前端设计交接状态

更新时间：2026-07-18

## 当前进行到哪一步

目前已完成 **最小主流程的视觉基准确认**，可以进入 Figma 还原或正式前端搭建阶段。

Canvas 一共规划了 4 个路由页面：

1. 全球博物馆地图首页 `MAP`
2. 芝加哥艺术博物馆数字画廊 `GAL`
3. 单件作品观看与艺术家对话 `ART`
4. 梵高人生路线 `ARI`

当前已经确认 4 张视觉基准图：`MAP` 的两个核心画面、`GAL` 的数字画廊默认画面，以及 `ART` 的作品观看与艺术家对话画面。进入 Figma 或前端实现时以这 4 张图作为视觉基准。

## 已确认、无需修改的原型

### 01 — 首页首屏

文件：`01-home-hero-approved.png`

已经锁定的设计：

- 左侧展示之前推荐过的艺术品。
- 中间展示今日推荐作品，是第一视觉中心。
- 右侧展示“与艺术家对话”入口，不展示尚未发布的未来作品。
- 对话入口使用圆角透明玻璃组件。
- 使用今日艺术家画作中的一只眼睛作为艺术家识别形象，不使用完整头像或机器人图标。
- 玻璃保持暖灰、干净、克制，与博物馆页面统一；不使用蓝紫霓虹玻璃效果。
- 对话入口只保留一句说明、一个问题提示和一个主要动作，不在首页展开聊天记录。
- 下方使用被视口裁切的深石墨色地球，并保留大型人文衬线标题 `CANVAS Library`。

### 02 — 首页下滑后的博物馆信息状态

文件：`02-museum-info-approved.png`

已经锁定的设计：

- 用户向下滚动后，地球移动到右侧，左侧展示今日作品所在博物馆的信息。
- 默认博物馆为当日推荐作品所在的博物馆，目前是芝加哥艺术博物馆。
- 地球可拖动旋转，并承担“全球艺术馆藏索引”的功能。
- 地球节点区分今日推荐、已开放、即将开放和城市聚合。
- 左侧只展示进入画廊前需要的核心信息，不堆叠开放时间、票务等详细资料。
- 主动作是“进入数字画廊”。

### 03 — 数字画廊默认状态

文件：`03-gallery-default-approved.png`

已经锁定的设计：

- 使用专辑封面式的横向作品轮播，不模拟实体展厅。
- 当前作品与底部窄资料栏构成一张完整圆角卡片。
- 两侧作品采用相同卡片结构，并降低视觉权重。
- 背景使用当前作品放大、模糊后的色彩场。
- 当前作品卡下方保留艺术家眼睛头像与对话入口。
- 点击当前作品后，作品卡翻转并进入作品详情页。

### 04 — 作品观看与艺术家对话状态

文件：`04-artwork-dialogue-approved.png`

已经锁定的设计：

- 左侧持续展示可放大的高清作品，是页面第一视觉主体。
- 作品只保留放大、缩小、拖动、复位和全屏功能。
- 右侧为单栏艺术家对话区域，不建立独立聊天页面。
- 对话使用编辑式文本排版，不使用普通聊天软件的彩色气泡。
- 梵高回答旁提供“查看依据”入口。
- 输入框固定在右侧栏底部，作品在对话过程中始终可见。
- 页面提供返回芝加哥艺术博物馆数字画廊的入口。

## 已确定的整体视觉方向

- 严肃、严谨、人文、安静，接近国际博物馆档案与艺术出版物。
- 暖石色页面背景、墨黑文字、深石墨色地球与观看空间。
- 艺术品是界面中主要的高饱和色彩来源。
- 大标题使用有人文气息的衬线字体；导航、按钮和元数据使用克制的无衬线字体。
- 避免低幼、卡通、贴纸、彩色气泡、普通聊天软件界面和过度圆角卡片。
- 透明玻璃只用于关键的艺术家对话入口，不扩散到整个产品。

## 当前最小流程

```text
博物馆信息
  → 进入数字画廊
  → 横向选择作品
  → 作品卡翻转进入详情页
  → 放大观看作品
  → 与梵高对话
  → 查看回答依据
  → 返回数字画廊
```

## 延期功能

以下内容不进入当前最小流程，后续重新论证：

- 作品热点与细节探索。
- 点击热点后的自动聚焦。
- “跟着梵高”艺术家生涯路线。
- 艺术家地点地图与阶段选择。
- 观展结束后的复杂分流。
