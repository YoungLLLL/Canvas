## 统一视觉方向

- 暖石色背景、墨黑文字与深石墨观看空间。
- 人文衬线字体负责标题与叙事，克制的无衬线字体负责导航和元数据。
- 艺术品是界面中唯一持续使用高饱和色彩的内容。
- 对话采用博物馆策展文本结构，不使用聊天气泡或机器人视觉语言。
- 所有状态保持作品优先、渐进披露和可恢复的浏览上下文。

这些图片用于视觉方向与 Figma 搭建参考，图中文字、字体、间距和真实馆藏数据仍需在 Figma 中校正。
